# H M Abrar Fahim Patwari - Personal Portfolio

A lean, responsive static portfolio website built with semantic HTML and modern CSS.

## Live Website
Hosted on GitHub Pages: [https://abrarfahim19.github.io/aboutme/](https://abrarfahim19.github.io/aboutme/)

## Features
- **Ultra-lean**: Single file HTML & CSS, zero external dependencies or JavaScript libraries.
- **Fast loading**: Instant load times with standard system fonts.
- **Responsive**: Clean presentation across mobile, tablet, and desktop devices.
- **Dark & Light Mode**: Automatic styling adaptation based on system `prefers-color-scheme`.
- **Print Friendly**: Clean layout when printed or exported as PDF.
